# Recursos para la pantalla de intermitencia

## Paleta

| Token | HEX | Uso recomendado |
| --- | --- | --- |
| Navy 900 | `#08263D` | Fondo principal y títulos |
| Navy 700 | `#064E7A` | Gradientes y profundidad |
| Blue 500 | `#139BD7` | Botones, enlaces y énfasis |
| Blue 300 | `#7DD3FC` | Ilustraciones y detalles |
| Surface | `#FFFFFF` | Tarjeta principal |
| Surface muted | `#F2F7FA` | Fondos secundarios |
| Text secondary | `#64748B` | Texto descriptivo |
| WhatsApp | `#25D366` | Acción de WhatsApp |

## Archivos

- `logo-faktu.png`: logotipo oficial descargado de faktu.net.
- `fondo-faktu.png`: fondo 16:9 sin texto ni interfaz.
- `icono-servidor-faktu.png`: ilustración PNG con transparencia.
- `design-tokens.css`: variables CSS de la paleta.

## Tipografía sugerida

Usar `Poppins`, con respaldo `Arial, sans-serif`.
